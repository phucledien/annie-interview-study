# Interview study book

A read-only, illustrated 10-day guide for a Business Analyst interview involving a public-health tools marketplace. Each day has a tab, visual memory aids, tables, practice and interview questions.

Each tab contains its own 30-minute study plan, relevant detailed notes, worked examples, answer tips and sources. Days 1–7 include expandable topic references; the former combined reference section has been distributed among the matching days. Healthcare content remains within Days 8–10.

## Read the guide

**[Open the study book](https://phucledien.github.io/annie-interview-study/)**

On iPad, open the link in Safari. Use Share → Add to Home Screen if you want a shortcut. Internet access is needed to load the hosted page; this is not an offline app.

Plan for 30 minutes each day, with optional work for a full hour. Days 8–10 have been adapted to a role supporting discovery and reuse of analytical resources for epidemic and pandemic intelligence. Simple illustrated stories connect the domain to research, artifact modelling, AI requirements, governance and day-to-day BA delivery.

Source links are included beside the relevant lessons. References include WHO's Collaboratory and public-health intelligence material, CDC, NIST, the GO FAIR Foundation and optional HealthIT.gov, HL7 and HHS background. Last checked: 30 October 2026. The guide is independent study material, not a WHO publication or endorsement.

## Behaviour and scope

- Lessons cannot be edited through the website. Tabs, disclosures and completion checkboxes remain interactive.
- Completion is stored in the browser on that device; it does not sync across devices.
- The teaching scenarios and example figures are fictional. They do not establish medical, legal or product requirements.
- HIPAA material is explicitly US-specific. Project rules require confirmation with the relevant domain and governance experts.
- This public repository contains the study website only. Employer/project-specific prompts were generalised for publication.

`index.html` is a self-contained static export. GitHub Pages serves the `main` branch from the repository root; no installation or build step is required.
